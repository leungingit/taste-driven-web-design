## 4. 原型与资产规范（阶段 4）

开始前：`gate.py check 4`。

### 4.1 原型
- 主方向复制为 `work/proto/v001.html`，合并用户指定的部分，补全所有区块。改版项目先做**样张页**（scope 为 sample-then-rollout 时）。
- 每轮修改另存新版本号，`record/changelog.md` 记一行（版本、改动、原因）。
- 偏离主线的尝试放 `work/proto/branch-{名称}/`，用决策让用户决定合入或放弃。
- **从 v001 起就令牌驱动**：所有视觉取值都可调——CSS 部分用变量，画布、着色器、粒子等用一份 JSON 配置。不要先写死再花一轮去抽取。
- **从 v001 起就可验证**：
  - 应用类：原型支持 `?demo=<状态>` 参数和一个可收起的演示面板，content.yaml 状态表里的每个状态都能切到；gate.py 会检查。
  - 有动效时：支持 `?t=<秒>` 冻结在指定时刻绘制、`?seed=` 固定随机数，并暴露手动触发入口（如手动触发一次数据刷新），方便截图和断言。
  - 短暂的效果（一闪而过的描边、过渡）用页面状态断言验证，不靠截图碰运气；测试脚本等待具体条件，不用固定时长等待。
- 改版项目：新增或修改一个外观参数时，如果 `user_customizable` 为 true，同步考虑它在设置页里的呈现。仅设计时只在原型中演示，不修改工程设置页。

### 4.2 资产规范 work/assets/spec.md
方向一定，就主动为 scope.asset_types 的**每一类**资产写规范，不等用户提出：

| 项 | 内容 |
|---|---|
| 用途与出现位置 | 哪些页面、什么尺寸的容器 |
| 尺寸与比例 | 导出尺寸、比例、@2x |
| 构图安全区 | 文字/按钮可能覆盖的区域、裁切规则 |
| 配色 | 允许的令牌、背景处理 |
| 风格 | 引用 traits 编号 |
| **细节密度下限** | 从本期已确认的基准资产提取实际可见特征，写成可逐条勾选的清单；按资产类型选取适用维度，不套用机械分件、紧固件或固定线宽级数 |
| 禁止项 | 例如纯色平涂、无结构的剪影、混用其他风格 |

### 4.3 基准资产
建一个 `role: "asset-benchmark"` 决策（artwork），每类资产让用户从已有资产中选出一个"就照这个标准做"的基准，存到 `media/assets/benchmark/`（衍生资产的过程图放 `media/assets/derived/`；设计并实施时最终资产写进项目源码里它真正的位置，仅设计时最终资产也留在本期设计目录，并记录未来目标位置）。细节密度下限从基准资产上逐条提取。

**闸门 4**：原型在 375/768/1440 下无横向滚动、无重叠；spec 覆盖每类资产；基准已选；gate approve。
