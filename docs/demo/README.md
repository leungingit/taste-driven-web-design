# README 演示与展示素材

本目录用于让读者体验技能内置的决策界面，以及复现项目 README 中的截图。产品「拾页」、文案和三个首页样张均为本仓库专门制作的虚构示例；它们不是客户案例，也不表示智能体在真实项目中的最终设计质量。

## 本地体验

在仓库根目录运行：

```bash
python3 docs/demo/serve.py
```

打开终端输出的本地地址。端口冲突时使用 `python3 docs/demo/serve.py --port 0`。依赖仅为 Python 3 标准库，服务只监听本机，不读取模型凭证或真实项目记录。

演示会在系统临时目录初始化独立记录，并设置用于展示的阶段 3 和示例题目；这不代表真实项目已经通过前序闸门。界面直接使用仓库中的 `scripts/decide_server.py`，没有另做一套展示用界面。可选择方向、填写备注、提交并在「回顾」查看答案。没有智能体接手等待，页面显示相应真实状态；提交后不会生成新方案或推进设计阶段。

按 `Ctrl+C` 关闭服务，临时项目随之清理。再次运行得到新的空白演示记录。

## 素材与复现

| 文件 | 内容与来源 |
|---|---|
| [directions.html](directions.html) | 用 HTML/CSS 制作的三种首页样张，使用系统字体，不加载外部图片、字体或脚本 |
| [question.json](question.json) | 实际决策服务读取的演示题目，样例类型为 `code-native` |
| [决策页截图](../assets/decision-preview.png) | 真实服务的题目区域截图；选 B，填写「保留 B 的刊物感，标题更克制一些。」，尚未提交 |
| [并排对比截图](../assets/compare-preview.png) | 真实服务的查看器截图；同时查看 B 与 A |
| [中文流程图](../assets/workflow.svg)、[英文流程图](../assets/workflow.en.svg) | 可直接编辑的 SVG 流程概览；不是运行界面截图 |

复现截图时先启动演示，等待全部样张加载完成，使用浅色界面：

1. 浏览器视口设为 1100 × 800，点击 B 的选择圆点并填写上述备注。截取整个题目卡片（`.dec`），得到决策页截图。
2. 点击 B 样张的放大按钮，再点「并排对比」，确认左侧为 B、右侧为 A。视口设为 1440 × 720，截取查看器（`#vw`）。
3. 不修改服务页面的样式或状态来隐藏提示，不把本地演示截图描述为真实交付案例。

README 使用相对路径引用所有图片，适用于 GitHub 展示和仓库克隆后的离线阅读。SVG 提供标题和文字描述，截图在 README 中提供替代文本与来源说明。
